# الوحدات وواجهات التفاعل (Modules & APIs)

## 1. FootingDesignModule

- الوظيفة: تنفيذ منطق تصميم قاعدة منفصلة طبقاً لمدخلات نصية.
- المدخلات (JSON مقترح):
  - `column_size`: { `b`, `h` } بالمليمتر.
  - `service_load`: حمل التشغيل بالكيلو نيوتن.
  - `soil_bearing_capacity`: إجهاد التربة المسموح (kN/m2).
  - `fc`, `fy`: خصائص الخرسانة والحديد.
  - `cover`: الغطاء الخرساني.
- المخرجات:
  - أبعاد القاعدة (B, L, t).
  - قيم التصميم (Mu, Vu، ضغط التربة الفعلي، نسب الأمان).
  - مخطط تسليح منطقي (أقطار، مسافات، عدد).

## 2. DxfDrawingModule

- واجهة عالية المستوى نحو خادم DXF عبر MCP.
- دوال منطقية، مثل:
  - `draw_isolated_footing(footing_design)`
- كل دالة تحوّل بيانات التصميم إلى سلسلة من استدعاءات أدوات الرسم (rectangles, polylines, text, dimensions…).

## 3. ReportingModule

- يبني من مخرجات التصميم نص تقرير منظم:
  - مدخلات.
  - خطوات الحساب.
  - نتائج الفحوصات.
  - جدول كميات بسيط.

## 4. FrontEndAdapter

- يعرّف كيف تتحدث واجهة المستخدم (Cline/Claude) مع LLM:
  - قوالب للمدخلات.
  - طريقة عرض المخرجات.
- يضمن أن جميع المدخلات تصل بصيغة متسقة إلى FootingDesignModule.
