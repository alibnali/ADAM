# P5-T04 — Engineer Review Checklist

## Purpose
ADAM outputs are **preliminary engineering aids**. Every output must be reviewed and stamped by a licensed engineer before construction use.

This checklist tells the engineer exactly what to verify.

---

## General (All Drawings)

- [ ] Project information correct (title, date, scale, engineer name)
- [ ] Drawing scale matches stated scale bar
- [ ] All dimensions are consistent and non-contradictory
- [ ] North arrow direction verified
- [ ] Sheet size and layout appropriate
- [ ] Revision cloud + delta marker if this is a revision

---

## Structural — Footing

- [ ] Soil bearing capacity (q_allow) verified by geotechnical report
- [ ] Footing size consistent with column grid
- [ ] Punching shear check values reviewed
- [ ] Reinforcement bar sizes available locally
- [ ] Cover meets local exposure requirements
- [ ] No conflict with underground utilities

---

## Structural — Beam

- [ ] Span and loading diagram verified against architectural plan
- [ ] Effective depth d consistent with cover and bar diameter
- [ ] Stirrup spacing does not exceed d/2 in high-shear zones
- [ ] Positive and negative moment reinforcement both shown
- [ ] Bar cutoff points meet ACI development length requirements
- [ ] Deep beam flag: if triggered, independent strut-and-tie design required

---

## Structural — Column

- [ ] Load takedown verified (axial load from all floors above)
- [ ] Eccentricity / biaxial bending considered if applicable
- [ ] Slenderness ratio kL/r checked against building's lateral system
- [ ] Tie spacing verified for seismic zone
- [ ] Column size consistent with architectural drawings

---

## Structural — Slab

- [ ] Loading (SDL + LL) matches building use
- [ ] Thickness meets fire rating requirements (local code)
- [ ] Temperature steel direction correct (perpendicular to main)
- [ ] Openings / penetrations not shown (ADAM does not model them)

---

## Structural — Shear Wall

- [ ] Seismic design category verified
- [ ] Boundary element requirement confirmed by project structural engineer
- [ ] Connection to foundation detailed separately
- [ ] Coupling beams (if any) designed separately

---

## MEP — Electrical

- [ ] Utility voltage and phase confirmed with power company
- [ ] Panel location accessible and meets clearance requirements
- [ ] Circuit breaker ratings match local availability
- [ ] GFCI/AFCI requirements per local code added
- [ ] Earthing/grounding system shown on separate drawing

---

## MEP — HVAC

- [ ] Cooling load matches actual orientation, glazing area, and insulation
- [ ] Equipment brand/model selection by MEP engineer
- [ ] Duct material and insulation specified
- [ ] Fire dampers at rated walls shown separately
- [ ] Fresh air intake location verified (away from exhaust)

---

## MEP — Plumbing

- [ ] Water pressure at inlet verified with authority
- [ ] Pipe material specified (PPR, HDPE, cast iron for drain)
- [ ] Cleanout locations shown
- [ ] Water heater location and capacity verified
- [ ] Grease trap required for kitchen (commercial)?

---

## Civil — Site Plan

- [ ] Plot boundary matches title deed / survey
- [ ] Setbacks comply with current local zoning regulation
- [ ] BCR and FAR within permitted limits
- [ ] Vehicular access and parking counted
- [ ] Rainwater drainage direction shown
